# Joe Like — application vitrine

Site mobile de l’artiste Joe Like : accueil, musique, concerts, à propos.
C’est un site statique : un fichier `index.html` et un dossier `images/`. Aucune installation nécessaire.

## Mettre en ligne sur GitHub Pages

1. Crée un dépôt sur GitHub et envoie-y tout le contenu de ce dossier (`index.html`, `images/`, `.nojekyll`).
2. Dans le dépôt : **Settings → Pages → Build and deployment**.
3. Source : **Deploy from a branch**, branche **main**, dossier **/ (root)**, puis **Save**.
4. Après une minute, le site est disponible à l’adresse `https://TON-PSEUDO.github.io/NOM-DU-DEPOT/`.

## Modifier le contenu

Ouvre `index.html` dans un éditeur de texte.

- **Photos** : remplace les fichiers `images/photo-01.jpg` à `photo-24.jpg` (format portrait 3:4, environ 900 × 1200 px). `photo-01.jpg` est aussi la photo en haut de l’accueil, `photo-02.jpg` celle de À propos.
- **Titres de musique** : cherche « Marée haute », « Néons », « Lumière du soir » (textes d’exemple à remplacer).
- **Concerts** : cherche « La Maroquinerie », « Transbordeur »… (dates d’exemple à remplacer).
- **Liens** : cherche `href="https://` pour retrouver Spotify, Apple Music, YouTube, Instagram, TikTok, Facebook et le label.
- **Couleurs** : tout en haut du fichier, les variables `--navy` (bleu marine) et `--pink` (rose).
